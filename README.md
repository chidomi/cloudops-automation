# CloudOps Automation

## Project Overview

This project demonstrates a hands-on DevOps workflow using Python, GitHub Actions, Docker, Terraform, and AWS.

## Project Goals

- Retrieve repository information using the GitHub REST API.
- Build a Python automation script.
- Automate testing and execution using GitHub Actions.
- Package the application using Docker.
- Provision AWS infrastructure using Terraform.
- Integrate GitHub Actions with AWS using OpenID Connect (OIDC).

## Technologies

- Python
- Git and GitHub
- GitHub Actions
- Docker
- Terraform
- AWS
